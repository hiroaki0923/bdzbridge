# プライバシーポリシー — RecBridge

最終更新: 2026-10-31

## 収集していません

RecBridge（以下「本アプリ」）は、利用者の情報を一切収集しません。開発者に送信されるデータ
はありません。解析ツール、広告、クラッシュレポートの収集を組み込んでいません。アカウント
登録もありません。

## 通信するのは、お使いのレコーダーとテレビだけ

本アプリが通信するのは、利用者が追加したブルーレイディスクレコーダーとテレビと、それらを
探すときに尋ねる同じネットワーク上の機器だけです。宛先は利用者が指定した（または同じ
ネットワーク上を探して見つけた）機器の IP アドレスで、通信は利用者のネットワークのなかで
行われます。開発者のサーバーはありません。
外部のサービスも使っていません。

テレビを登録するときは、テレビの画面に出る番号を入力します。テレビには、本アプリが
「RecBridge」という名前と、本アプリが作った識別子で登録されます。この識別子は、iPhone や
利用者を表すものではありません。

外出先から使う場合は、利用者自身が用意した VPN などを通じて自宅のネットワークに入ることを
想定しています。その経路も利用者の管理下にあり、本アプリが別の宛先に送ることはありません。

## iPhone に保存されるもの

次のものが iPhone のなかに保存されます。いずれも iPhone から出ません。

- レコーダーから読み出した番組表（チャンネル、番組名、番組内容、放送局のロゴ）
- レコーダーの IP アドレス、MAC アドレス（省電力状態のレコーダーを起こすために使います）と、
  レコーダーが自分を名乗るときの識別子（保存した番組表や送信待ちの予約がどのレコーダーの
  ものかを見分けるために使います）
- レコーダーに登録されている USB ハードディスクの名前など（起こした直後のレコーダーは
  USB ハードディスクが無いように答えるので、それまでに分かっていたものを使います。
  別のレコーダーにつなぐと消えます）
- 録画した番組の番組内容（重複した録画を探すときにレコーダーから読み出したもの。
  別のレコーダーにつなぐと消えます）
- テレビの IP アドレスと MAC アドレス（MAC アドレスは、同じテレビかどうかを見分けるために
  使います。テレビの電源を入れるためには使いません）
- テレビの登録情報（本アプリの識別子と、テレビから受け取った認証の情報）。キーチェーンに、
  この iPhone だけで読める形で置き、アプリのファイルにある鍵で暗号化しています。
  バックアップから別の iPhone に移ることはありません
- 表示の設定（チャンネルの並び順と非表示、既定の録画モード、表示形式）
- レコーダーやテレビに届かなかったときに預かった録画予約（送信待ちの予約）と、その宛先。
  宛先の機器に送れた時点で消えます
- すでに通知した内容の控え（同じことを繰り返し通知しないために使います）

アプリを削除すると、これらは消えます。ただし、テレビの登録情報は、キーチェーンに残ることが
あります。それを開く鍵はアプリのファイルにあり、アプリと一緒に消えるので、残ったものは
だれにも読めません。もう一度入れた本アプリにも読めません。

設定画面でテレビを外すと、テレビの登録情報とその鍵、テレビのアドレス、テレビ宛ての送信待ちの
予約は、その場で消えます。テレビの側に残る「RecBridge」の登録は、本アプリからは消しません。

## 通知

通知を許可した場合、次のときに通知します。

- 送信待ちの予約をレコーダーやテレビに送ったとき（送れなかったときも含みます）
- 送信待ちの予約が、レコーダーやテレビに届かないまま始まりそうなとき
- レコーダーの残り容量（本体の HDD と、つないだ USB ハードディスクのそれぞれ）が少なく
  なったとき

通知の内容は iPhone のなかで作られ、どこにも送信されません。

## ローカルネットワークへのアクセス

レコーダーとテレビを探すために、同じネットワーク上の機器へのアクセスの許可を求めます。探す
ときは、同じネットワーク上の各アドレスに、レコーダーかテレビかを尋ねます。使うのは、
レコーダーとテレビを見つけることと、見つけた機器とやりとりすることだけです。
