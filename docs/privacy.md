# プライバシーポリシー — RecBridge

最終更新: 2026-11-24

## 収集していません

RecBridge（以下「本アプリ」）は、利用者の情報を一切収集しません。開発者に送信されるデータ
はありません。解析ツール、広告、クラッシュレポートの収集を組み込んでいません。アカウント
登録もありません。

## 通信するのは、お使いのレコーダーとテレビだけ

本アプリが通信するのは、利用者が追加したブルーレイディスクレコーダーとテレビと、それらを
探すときに尋ねる同じネットワーク上の機器だけです。宛先は利用者が指定した（または同じ
ネットワーク上を探して見つけた）機器の IP アドレスで、通信は利用者のネットワークのなかで
行われます。開発者のサーバーはありません。
外部のサービスも使っていません。

テレビを登録するときは、テレビの画面に出る番号を入力します。テレビには、本アプリが
「RecBridge」という名前と、本アプリが作った識別子で登録されます。この識別子は、iPhone や
利用者を表すものではありません。

テレビに「RecBridge ヘルパー」（以下「ヘルパー」。後述）を入れて、本アプリをヘルパーに
登録する場合は、本アプリはヘルパーとも通信します。ヘルパーはテレビのなかで動くので、宛先は
テレビの IP アドレスです。

ヘルパーに登録するときは、ヘルパーがテレビの画面に出す 6 桁の番号を入力します。本アプリは、
ヘルパーに「RecBridge (iPhone)」という名前で登録されます。この名前はどの iPhone でも同じで、
iPhone や利用者を表すものではありません。登録すると、本アプリはヘルパーから認証の情報を
受け取り、それを添えて番組表を尋ねます。

本アプリがヘルパーに番組表を尋ねるのは、番組表をテレビから受け取るときだけです。ヘルパーに
登録してあれば、レコーダーを追加していないとき、追加したレコーダーが番組表に対応していない
とき、設定の「番組表の取得元」でテレビを選んだときに、番組表をテレビから受け取ります。

本アプリを開いていなくても、午前 2 時を過ぎてから iPhone が本アプリを動かすと、本アプリは
レコーダーやテレビと通信することがあります。送信待ちの予約を送ったり、レコーダーか
ヘルパーから番組表を受け取ったりします。ショートカット App で送信待ちの予約を送るときも、
本アプリはレコーダーやテレビと通信します。

外出先から使う場合は、利用者自身が用意した VPN などを通じて自宅のネットワークに入ることを
想定しています。その経路も利用者の管理下にあり、本アプリが別の宛先に送ることはありません。

## iPhone に保存されるもの

次のものが iPhone のなかに保存されます。本アプリが、これらを開発者や外部のサービスに送る
ことはありません。

- レコーダーから読み出した番組表か、ヘルパーを通してテレビから受け取った番組表（チャンネル、
  番組名、番組内容、放送局のロゴ）
- レコーダーの IP アドレス、MAC アドレス（省電力状態のレコーダーを起こすために使います）と、
  レコーダーが自分を名乗るときの識別子（保存した番組表や送信待ちの予約がどのレコーダーの
  ものかを見分けるために使います）
- レコーダーに登録されている USB ハードディスクの名前など（起こした直後のレコーダーは
  USB ハードディスクが無いように答えるので、それまでに分かっていたものを使います。
  別のレコーダーにつなぐと消えます）
- 録画した番組の番組内容（重複した録画を探すときにレコーダーから読み出したもの。
  別のレコーダーにつなぐと消えます）
- テレビの IP アドレスと MAC アドレス（MAC アドレスは、同じテレビかどうかを見分けるために
  使います。テレビの電源を入れるためには使いません）
- テレビの登録情報（本アプリの識別子と、テレビから受け取った認証の情報）。キーチェーンに、
  この iPhone だけで読める形で置き、アプリのファイルにある鍵で暗号化しています。
  バックアップから別の iPhone に移ることはありません
- ヘルパーの登録情報（ヘルパーから受け取った認証の情報）。キーチェーンに、この iPhone だけで
  読める形で置いています。バックアップから別の iPhone に移ることはありません。テレビの
  登録情報と違い、アプリのファイルにある鍵での暗号化はしていません。この認証の情報で
  受け取れるのは、テレビの番組表と、ヘルパーが伝えるテレビとヘルパーの様子（後述）だけです。
  録画の予約には使えません
- 表示の設定（チャンネルの並び順と非表示、既定の録画モード、表示形式）と、「番組表の取得元」
  で選んだもの
- レコーダーやテレビに届かなかったときに預かった録画予約（送信待ちの予約）と、その宛先。
  宛先の機器に送れた時点で消えます
- すでに通知した内容の控え（同じことを繰り返し通知しないために使います）

アプリを削除すると、これらは消えます。ただし、テレビの登録情報は、キーチェーンに残ることが
あります。それを開く鍵はアプリのファイルにあり、アプリと一緒に消えるので、残ったものは
だれにも読めません。もう一度入れた本アプリにも読めません。

ヘルパーの登録情報も、キーチェーンに残ることがあります。こちらは、アプリのファイルにある鍵で
暗号化していません。そのため、残っていた場合は、もう一度入れた本アプリでテレビを追加すると、
それをそのまま使います。残したくないときは、アプリを削除する前に、設定画面で
「ヘルパーの登録を解除」を選んでください。

設定画面で「ヘルパーの登録を解除」を選ぶと、ヘルパーの登録情報は、その場で iPhone から
消えます。テレビから受け取った番組表は残ります。レコーダーから番組表を受け取ると、それに
置き換わります。ヘルパーの側に残る「RecBridge (iPhone)」の登録は、本アプリからは消しません。

設定画面でテレビを外すと、テレビの登録情報とその鍵、ヘルパーの登録情報、テレビのアドレス、
テレビ宛ての送信待ちの予約は、その場で消えます。テレビから受け取った番組表は、ヘルパーの
登録を解除したときと同じく残ります。テレビの側に残る「RecBridge」の登録と、ヘルパーの側に
残る「RecBridge (iPhone)」の登録は、本アプリからは消しません。

## 通知

通知を許可した場合、次のときに通知します。

- 送信待ちの予約をレコーダーやテレビに送ったとき（送れなかったときも含みます）
- 送信待ちの予約が、レコーダーやテレビに届かないまま始まりそうなとき
- レコーダーの残り容量（本体の HDD と、つないだ USB ハードディスクのそれぞれ）が少なく
  なったとき

通知の内容は iPhone のなかで作られ、どこにも送信されません。

## ローカルネットワークへのアクセス

レコーダーとテレビを探すために、同じネットワーク上の機器へのアクセスの許可を求めます。探す
ときは、同じネットワーク上の各アドレスに、レコーダーかテレビかを尋ねます。使うのは、
レコーダーとテレビを見つけることと、見つけた機器とやりとりすることだけです。

## テレビに入れるヘルパー

ヘルパーは、利用者がテレビに入れる、本アプリとは別のアプリです。テレビが放送から受け取った
番組表を、本アプリに渡します。

ヘルパーは、テレビが起動すると自分で動き始めます。テレビの番組表の写しを作り、テレビのなかの
ヘルパー自身の保存場所に置きます。置くのは最新の写しだけで、古い写しは残しません。テレビの
番組表が変わると、しばらくして作り直します。テレビの番組表を書き換えることも、テレビの電源を
入れることもありません。

テレビの番組表のうち、ヘルパーが保存して本アプリに渡すのは、テレビのチューナーが書いた
放送局、番組、放送局のロゴだけです。テレビの番組表には、ほかのアプリの局や番組が入っている
こともあります。ヘルパーはテレビの番組表をまとめて読むので、写しを作るたびにそれらも
読みますが、保存も、本アプリに渡すこともしません。視聴履歴やおすすめは読みません。

番組表のほかに、ヘルパーは次のことを調べます。

- 番組表を読む許可があるか
- チューナーのアプリが入っているか
- テレビの画面がついているか
- テレビの時刻と時間帯
- テレビが起動した時刻
- テレビの番組表が最後に書き換わった時刻
- ヘルパーが使える空き容量

これらは、ヘルパー自身の様子（版や、写しを作った時刻と件数など）と一緒に、登録した端末に
伝えます。本アプリは、このうち画面の様子、時刻と時間帯、起動した時刻、空き容量を使いません。
テレビの番組表が最後に書き換わった時刻は、写しの様子と一緒に、テレビのなかに保存します。

番組表と、上に書いたテレビとヘルパーの様子は、テレビの画面に出る番号で登録した端末にだけ
渡します。登録していない端末にわかるのは、ヘルパーが動いていることとその版、いま登録を
受け付けているかどうかだけです。

ヘルパーは、登録した端末ごとに、ヘルパーが作った識別子、端末が名乗った名前（本アプリなら
「RecBridge (iPhone)」）、登録した日時、最後に使われた日時を、テレビのなかに保存します。
認証の情報そのものは保存せず、照らし合わせるための値だけを保存します。端末の IP アドレスは
保存しません。

ヘルパーは、尋ねられたときに答えるだけで、自分からどこかへ送ることはありません。開発者に
送るものもありません。解析ツールや広告は組み込んでいません。

登録は、テレビでヘルパーを開き、「登録した端末」の一覧で「取り消す」を選んでから、確かめる
画面で「登録を取り消す」を選ぶと取り消せます。本アプリで「ヘルパーの登録を解除」を選んでも、
この一覧からは消えません。
