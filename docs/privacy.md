# プライバシーポリシー — BD Bridge

最終更新: 2026-10-02

## 収集していません

BD Bridge（以下「本アプリ」）は、利用者の情報を一切収集しません。開発者に送信されるデータ
はありません。解析ツール、広告、クラッシュレポートの収集を組み込んでいません。アカウント
登録もありません。

## 通信するのは、お使いのレコーダーだけ

本アプリは、利用者が登録したブルーレイディスクレコーダーとだけ通信します。宛先は利用者が
指定した（または同じネットワーク上を探して見つけた）レコーダーの IP アドレスで、通信は
利用者のネットワークのなかで行われます。開発者のサーバーはありません。外部のサービスも
使っていません。

外出先から使う場合は、利用者自身が用意した VPN などを通じて自宅のネットワークに入ることを
想定しています。その経路も利用者の管理下にあり、本アプリが別の宛先に送ることはありません。

## 端末に保存されるもの

次のものが iPhone のなかに保存されます。いずれも端末から出ません。

- レコーダーから読み出した番組表（チャンネル、番組名、番組内容、放送局のロゴ）
- レコーダーの IP アドレス、MAC アドレス（省電力状態のレコーダーを起こすために使います）と、
  レコーダーが自分を名乗るときの識別子（保存した番組表や預かった予約がどのレコーダーの
  ものかを見分けるために使います）
- 録画した番組の番組内容（重複した録画を探すときにレコーダーから読み出したもの。
  別のレコーダーにつなぐと消えます）
- 表示の設定（チャンネルの並び順と非表示、既定の録画モード、表示形式）
- レコーダーに届かなかったときに預かった録画予約。レコーダーに登録できた時点で消えます

アプリを削除すると、これらはすべて消えます。

## 通知

通知を許可した場合、預かっていた録画予約をレコーダーに送ったとき（送れなかったときも
含みます）、レコーダーの残り容量が少なくなったときに通知します。通知の内容は端末のなかで
作られ、どこにも送信されません。

## ローカルネットワークへのアクセス

レコーダーを探すために、同じネットワーク上の機器へのアクセスの許可を求めます。使うのは
レコーダーを見つけることと、見つけたレコーダーとやりとりすることだけです。
